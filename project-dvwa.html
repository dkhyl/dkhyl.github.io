PROJECT · WEB SECURITY AUTOMATION

DVWA Automation

My first hands-on project with Python. Built as a beginner exercise to learn libraries like Requests and BeautifulSoup, this project automates basic web scraping and interaction tasks against Damn Vulnerable Web Application (DVWA) at the low security level.

Completed Python · DVWA · Web Exploitation

01 / OVERVIEW

What this project covers

The starting point

This was my first real Python project. The goal wasn't to build a sophisticated tool - it was to learn how Python works with HTTP requests, HTML parsing, and simple automation. DVWA at the low security level was the perfect practice target because the responses are predictable.

Every script here is a learning artifact: some are rough, some are clean, but all of them show the progression from "how does this work?" to "I can build this."

02 / WHAT I PRACTICED

Topics I explored

◈

HTTP Requests with Python

Using the Requests library to send GET/POST requests, manage sessions, and handle cookies against a web application.

⚡

HTML Parsing & Scraping

Parsing HTML responses with BeautifulSoup to extract data - the foundation of any web scraping work.

⌘

Form Automation

Automating form submissions and login flows - reading input fields, sending crafted data, and verifying responses.

◎

Basic Web Exploitation

Practicing SQLi, XSS, and command injection at the DVWA low security level - the entry point for understanding how these flaws work.

03 / LEARNING NOTES

What I learned

This project gave me a working understanding of how HTTP actually works - sessions, cookies, and form data - and how Python can interact with a web application through libraries like Requests and BeautifulSoup.

It was the foundation I needed before moving into more advanced work. The concepts I practiced here - request handling, HTML parsing, and session management - became the building blocks for every web security project I've worked on since.
