PROJECT · OSINT · BASH SCRIPTING

Search4Me

A lightweight Bash tool built after a Capture The Flag competition to automate a routine part of OSINT work - searching the same query across multiple sites. The tool is intentionally simple: its purpose was to learn Bash scripting by building something genuinely useful, not to compete with professional OSINT platforms.

Completed Bash · Linux · OSINT

01 / ORIGIN

Where it started

After a CTF

During a Capture The Flag competition, I found myself repeatedly searching the same username, domain, or keyword across multiple OSINT sites - the same manual clicks, over and over. I wrote a small Bash script to automate that loop, and Search4Me was born.

It was my first real Bash tool. The code is simple, the feature set is minimal, and that's the honest truth. What matters to me is that it solved a real problem I had, and it taught me the fundamentals of shell scripting.

02 / FEATURES

What the tool does

◈

Multi-Site Search

Runs a single query across a list of predefined OSINT search targets - usernames, domains, or keywords.

⚡

Menu-Driven Interface

A numbered menu lets the user pick a category without remembering URLs or opening a browser manually.

⌘

Pure Bash

No dependencies, no installation, no setup. Runs on any Linux system with a standard shell.

◎

Editable Target List

The list of search sites is stored in a plain text file - adding or removing targets requires no code changes.

04 / NOTES

Design decisions

Search4Me was designed with simplicity as a deliberate choice. Pure Bash means it runs on any Linux system without installation or dependencies - download it, run it, and it works. The script is structured with clear functions for each action, keeps the target list in a separate file for easy customization, and handles user input safely.

The tool is not advanced, and I won't pretend it is. But it solved a real problem I had during a CTF, and building it taught me how to think in shell - functions, loops, input handling, and the discipline of automating a repetitive workflow. That mindset became the foundation for every scripting task I've taken on since.
